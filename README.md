# Tic Tac Toe Game – C++ 🎮

A simple console-based Tic Tac Toe game written in C++. This project allows two players to play the classic Tic Tac Toe game in the terminal.

## 🚀 Features
- Two-player mode
- User-friendly console interface
- Win detection
- Draw detection
- Replay option

## 🛠️ Technologies Used
- C++
- Standard Input/Output

## 📂 Project Structure
tic-tac-toe-cpp/
│── main.cpp
│── README.md

## ▶️ How to Run
1. Clone the repository:
   git clone https://github.com/your-username/tic-tac-toe-cpp.git

2. Compile the program:
   g++ main.cpp -o tictactoe

3. Run:
   ./tictactoe
